# Reporting a security issue

Use **Security → Report a vulnerability** in this repository to contact the maintainers privately. Include the affected version or commit, the impact, and enough detail for the maintainers to investigate. Keep wallet keys, recovery phrases, credentials and personal information out of any report.

If the repository's private reporting form is unavailable, ask for a private reporting channel through the [BDAG Community contact page](https://bdag.community/contact). Keep the report itself private until the maintainers confirm where to send it.
