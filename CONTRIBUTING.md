# Contributing to BDAG Community

Fork this repository, start your work from `develop`, and open a pull request to `develop`. Describe the problem, the change, and how you verified it. Use the repository README to run the project and its checks locally. Keep changes focused, preserve licence notices, and confirm that you have the right to submit included code and assets under their applicable terms.

Francois (`@franco-is`) and Jeremy (`@strattice`) maintain the protected branches. Either can approve an outside contribution. When one maintainer authors a pull request, the other reviews it. New changes can require another approval. Maintainers promote reviewed `develop` changes through a separate pull request to `main`.

For a security issue, follow [SECURITY.md](SECURITY.md) and keep sensitive details out of public issues and pull requests.
